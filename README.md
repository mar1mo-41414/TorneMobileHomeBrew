# torne mobile HomeBrew エディション

Sony のサポート終了後も、公式ファームウェアの nasne をスマートフォンから操作し続けるための、非公式・個人開発のクライアントアプリです。iOS / Android の両対応です。

## 現状

v1.0.0 をリリースしました。配布物 (IPA / APK) は GitHub Releases から入手できます。開発の経緯・設計・検証記録は [docs/plan.md](docs/plan.md) にまとめています。

## v1 の範囲

- nasne の発見・登録
- 本体・HDD・チューナー等の情報取得
- 録画予約の一覧・作成・更新・削除
- 録画タイトル一覧の表示

録画の再生は DTCP-IP の資格情報が必須となるため v1 では未実装とし、アプリ内にその旨を通知します。

## 動作条件

- 公式ファームウェアの nasne (検証は FW 2.60)
- iOS 15.0 以降 / Android 10 (API 29) 以降
- nasne と同じ LAN に接続された端末

## インストール

### iOS

署名なし IPA を配布しています。LiveContainer または AltServer 等でサイドロードしてください。

### Android

APK を直接インストールしてください (提供元不明アプリのインストール許可が必要です)。

## 使い方

1. アプリを起動し、「設定」タブで nasne を登録します。「LAN 内の nasne を探す」で発見できるほか、IP アドレスでの手動登録もできます。
2. 「ホーム」で本体・HDD の状態、「予約」で録画予約の管理、「録画済み」で録画タイトル一覧が使えます。

## 既知の制限

- 録画の再生は未実装です (上記のとおり)。
- iOS のサイドロード環境では SSDP による発見が動作しないため、「探す」ではサブネット走査が使われます。見つからない場合は手動登録をお試しください。
- 番組情報は「現在・次の番組」の表示のみで、番組表 (EPG グリッド) は未実装です。

## 技術方式

- アプリ識別子: com.markun.tmhb
